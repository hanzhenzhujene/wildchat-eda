# Data and source attribution

The root MIT license covers this repository's original analysis and interface code. It does not relicense source conversations, source annotations, or third-party papers.

- **WildChat:** [WildChat: 1M ChatGPT Interaction Logs in the Wild](https://arxiv.org/abs/2405.01470), Yenting Zhao et al. (2024). The [pinned WildChat-4.8M card](https://huggingface.co/datasets/allenai/WildChat-4.8M/blob/c827c6df8fcf008219ffaffa4d1dd77491099367/README.md) states **ODC-BY 1.0**. This repository includes derived statistics and selected excerpts already displayed in the public hub. Marked redactions and AI paraphrases remain distinct from source text. Attribute WildChat when reusing these materials.
- **Microsoft topic/task annotations:** [adopt-adapt-wildchat](https://github.com/microsoft/adopt-adapt-wildchat/tree/b4e77e44b62ba2ddd0f7b53667b218e345faba09). Its software license is MIT. A separate license for annotation data is not stated in the inspected release; do not infer that the software license relicenses underlying conversations. This repository includes aggregate counts, taxonomy definitions and provenance, not a bulk copy of released record-level annotations.
- **Other conversation datasets:** the [comparison table](docs/DATASETS.md) links to their own terms. No LMSYS, PRISM, OpenAssistant or UltraChat records are redistributed here.

Generated charts describe the attributed source data. Preserve their source and denominator when reusing them. Research-paper links provide references; the papers themselves are not hosted in this repository.
